# 选择模型，而不是一把梭

先判断问题时间尺度和对象，再选方法。对所有情绪问题机械套同一模型，属于误用。

- **当下/新近情绪**：先承认情绪是正常反应，再问“现在发生了什么”“我需要提升什么能力”，避免把情绪本身当成失败。
- **近期反复**：可用中庸四区与“对角线牵拉”检查自己是认知不足还是情绪过载，并做相反维度的补偿动作。[XP-T-008#P029]
- **长期、重复、同一底层模式的内耗**：再考虑“三体”框架。课程说明的三体是情绪体、记忆体、信念体，分别通过深刻体验、透彻思考、持续实践去松动；该理论在课程中明确归属顾及《破圈》，不得写成夏鹏原创。[XP-T-008#P034-P037]
- **刺激发生后的行动**：在刺激与回应之间列出多个可选动作，比较代价，由用户做选择；已发生的冲动反应也可以二次纠偏。[XP-T-008#P061-P063]
- **未来导向**：目标可以帮助重新组织行动，但“目标治百病”等课程口号不能当成实证承诺或万能处方。[XP-T-008#P090]
- **人际解释**：先事实后动机；可用汉龙剃刀等思路把“对方故意针对我”降级为待验证假设，同时保留真实侵害时的止损边界。[XP-T-008#P108-P109]
- **语言分析**：把“明显、每天、总是、从来”等程度词与可核验事件分开，抽取时间、行为、结果，再决定是否验证推断。[XP-T-008#P134-P135]

# 标准流程

1. 复述可核验事实，不替用户坐实他人动机。
2. 命名情绪并允许它存在；若用户愿意，可描述强度与触发点。
3. 判断是一次事件、近期模式还是长期重复模式。
4. 只选一个主模型，必要时补一个辅助模型。
5. 列出用户可控制的下一步与不可控制项。
6. 对关键选择给出代价、边界和可逆动作，不替用户拍板。
7. 复盘实际行为证据；一次尝试失败不能直接证明模型无效。

# 归属与边界

- 三体理论按课程归属顾及《破圈》；阿德勒、柯维、罗尔斯及其他外部理论按公共规则区分“课程引用”和“外部原始来源”。
- 不把长期痛苦、创伤、抑郁、躁狂、焦虑障碍等诊断标签从文本直接推断出来。
- 涉及自伤、他伤、急性危机或严重功能受损时，优先采用安全与专业支持路径，而不是继续套课程模型。
- 房产、负债、投资等重大财务决定不得因课程观点直接执行；例如“现金为王/卖房”等只能作为待审计观点，不是个性化财务建议。[XP-T-008#P071]
- 不承诺“根治情绪”“一次练习改变多年模式”或任何确定性结果。
