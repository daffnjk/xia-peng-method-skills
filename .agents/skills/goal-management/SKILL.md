# 触发场景

- 领导布置工作；
- 经营/项目会议结束；
- 与领导、同事或下属对齐目标；
- 周会、月会、复盘会。

# 第零步：情境智慧

检索或向用户确认：
- 组织战略与本周期目标；
- 领导风格和汇报偏好；
- 用户的优势、短板与职责；
- 关键同事、依赖和协作关系；
- 已有资源、预算与时间。

# 核心流程

1. **确认目标口径**：指标定义、基线、截止时间、责任人、成功阈值。例：“营收”是签约额还是到账额。
2. **拆关键路径**：输出必要动作、前后依赖和关键假设。
3. **调用模型**：SMART、OKR、KPI、平衡计分卡、Sprint、ART、PDCA、GRAI。若模型卡定义缺失，必须标记为工程知识缺口。
4. **资源—时间—目标权衡**：按来源中的 ART，A=目标，R=资源，T=时间；固定其中两项时，明确第三项需要调整。
5. **排优先级和节奏**：P1/P2/不做项、日程、负责人和检查点。
6. **汇报与证据链**：定义汇报频率、模板、决策记录和责任边界。
7. **执行后沉淀**：周报、实际结果、差距原因、规律、作品集与知识库。
8. **月度学习报告**：总结用户在目标管理上的长板、弱项和下一月训练重点。

# 输出

- 目标确认清单
- 关键路径与 OKR/KR 草案
- 资源和日程表
- 汇报模板
- 风险与决策记录
- 复盘与沉淀清单

# 禁止事项

- 不自行编造业务数字、转化率或组织关系。
- 不为了“防甩锅”制造对立；应建立透明、可审计的责任与决策记录。
- 数据未核验时不得声称方案可直接上会。
