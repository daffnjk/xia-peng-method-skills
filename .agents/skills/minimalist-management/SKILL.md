# 1. 场景、痛点、结果

适用：新接手或被提拔带团队；制定团队目标并选 KPI 还是 OKR；团队会开成争吵或一言堂；下属不主动、事事请示；绩效面谈与奖金设计；授权边界不清；想按阶段拉升团队效率。

痛点：做过程管理导致牛人不服管、烂人甩锅、其他人躺平；目标喊口号不具体不考核；追问原因、争对错把团队带成巨婴；领导包办一线工作；绩效只有结果没有过程、画饼不兑现。

结果：一套目标—授权—激励的管理主循环方案；一次可执行的绩效面谈或团队会议流程；新接团队的分阶段行动清单。所有输出标明【材料明确表达】【材料归纳】【工程化外推】【材料不足】。

不适用：个人职业规划与转岗决策（用 career-planning）；以个人目标拆解为主（用 goal-management，本 Skill 只补团队视角）；只问课程原意时，不强制输出管理方案；涉及真实解聘、降薪等人事动作，只给分析，执行须用户按劳动法与公司制度自行审批。

# 2. 思维模型与来源

封装结构来自 `scene-skill-builder`。管理方法来自夏鹏《极简管理课》，来源 `01_source/reviewed/XP-T-007_reviewed.txt`（141 段锚点，assurance 为 location_checked_not_semantic_verification；纠错记录见 `01_source/inbox/XP-T-007/correction_candidates.csv`）。核心模型已登记知识卡（XP-P-088—103、XP-M-035—041 及 SMART/OKR/KPI 补充）；未覆盖细节按【材料归纳】处理，精确主张回查 reviewed 或 raw 原稿并给短摘录。

核心命题：管理就是让下属明白什么是最重要的；管理 ≈ 目标管理，约占管理工作 80%，授权约 20%，激励约 10%（加分项）。反对过程管理（早请示晚汇报），过程交给员工，领导在中段看外部、节点收货。

按需取用，不机械串联：

- **KPI / OKR 选择**：熟悉业务、体力劳动、重复性、标准化、稳定环境、成本领先 → KPI（自上而下拆解）；探索业务、知识劳动、创造性、非标/个体小闭环、变动环境、差异化 → OKR（定方向+个人响应）；可混用（探索的用 OKR、执行的用 KPI）；OKR 更培养主动性——给方向后多问员工"你们想怎么做"。
- **好目标四原则**：① SMART——具体可测可描述无歧义可传递，必须白纸黑字写下来；可测要答四问（怎么测/谁来测/频率/测完干什么，测完必须连激励或优化）；可达成=外部对标（竞品数据、假扮顾客、招竞对员工、行业交流）+内部资源匹配+历史数据；相关性=大拆小、小聚大；时间表=给节奏、中段授权。② 一致性——个人多目标不冲突（一阶段最好单一目标）、团队打一个北极星指标、用"下探一级问目标"检验上下级口径。③ 阶段性——一个目标只服务一个阶段，到期复盘切换。④ 调动性——组织目标=个人目标的放大器；领导的目标也是个人目标：服务/管理/帮助每个成员实现目标，不得以"组织目标"自居。
- **目标制定流程**：会前（使命愿景价值观对齐→战略定性差异化或成本领先→外向性指标：看对手、看用户→摸数据不讨价还价）→ 会上（呈现外部现状+SWOT 由大家列→列问题与挑战，领导提问让团队说→散会各自书写目标与时间表）→ 会后汇总分层（S 级给方法要资源用 OKR；A 级半主动谈心激活；B 级直接 KPI 拆任务；D 级不写乱写，绩效定清、白纸黑字、走优化）→ 口诀：下属说、领导改（不当场改）、大家认、照着来、开始试。
- **六顶帽子开会**：白=事实数据、绿=创造想象、黄=价值肯定、黑=逻辑批判（非情感批判）、红=情绪直觉、蓝=控制流程做结论（领导戴，或重点培养擅长者）。顺序不必然（讲师顺手顺序：红→白→绿→黑→黄→蓝），但每色至少一次、时间均衡（黑色忌过多）；戴帽摘帽要有仪式感；同步思维模式但表达不同角度（反对"我也觉得"式邯郸学步）；强者后发言；平时练习识别他人当前戴的帽子并用同色回应。
- **面对事实解决问题**：只问两个问题——事实是什么、问题是什么；主观感受上认同、客观上追问；不问原因（一问就成保姆型领导）、不争对错、不归责任（"问题在这儿谁来解决"，解决问题的是功臣）。麦肯锡七步：定义问题（不解决会怎样/解决会怎样，问题要"疼了"再解）→ 分解**要素**（不是原因；如 收入=用户数×单笔）排优先级 → 计划+时间表+责权利（专家掌权）→ 取证小规模验证（MVP）→ 结论 → 大规模行动；不成立拉回第一步。管理是实践，验证不在逻辑而在成果。
- **通过事管人，通过人做事**：管理的对象是事，人的动词是激励。尊重人、承认私利并翻译成与组织挂钩的工作目标；汉龙剃刀（先假设善意，博弈式回应，真恶直接处理）；相信人自驱、能学习、能担责；软性沟通+刚性绩效（说软话办硬事）；做事过程中认苦劳（认同情绪不认同做法），节点只认功劳；按意愿×能力两维度区分员工。
- **情景领导力**：S1 命令型（高指导低支持）↔ D1 有意愿无能力；S2 教练型（双高）↔ D2 能力升意愿降，最耗时，次序不可变：倾听→参与→反馈→指导→引导（答案从员工嘴里说出）；S3 支持型（低指导高支持）↔ D3 熟事愿做新事胆怯，鼓励试错；S4 授权型（双低：观察倾听鼓励）↔ D4 双高。评估维度：知识（what）/技能（how）/动力/自信。对 D4 用 S1—S3 = 过于管理（背后是不信任，资深老员工尤其如此）；对 D1—D3 用 S4 = 疏于管理。目标权在任何授权中都不能授出去。
- **授权与决策**：责=目标（不可授）；权=资源权+决策权（授权后又派人监督等于没授）；利=个人与组织共赢。决策的目的是执行而非正确——正确性由执行结果判定；决策必须带预先假定效果（即 SMART 工作目标，如"涨价10%拉动收入30%"）；集体决策、个人负责（反例：个人决策集体负责）。常规事靠 SOP 授权给一线，非常规事领导拍板后沉淀回 SOP（贝索斯：少做决策）；权衡决策迟滞损失 vs 错误决策损失；员工的决策力从失败中学，领导承担试错学费并复盘常规化；流程设计用两把剃刀：奥卡姆（如无必要勿增实体，流程尽量简单）+汉龙（信任人，没有完美的系统只有不断完美的人）；一定时间内不频繁变动。
- **激励与绩效面谈**：人会成为他所期望的样子——员工自己得有"1"，领导在外部环境补零；反复打压会造出习得性无助。期望理论：合理目标（对标而来，跳一跳够得着）+下属认同感（OKR 下属写领导改、集体决策、入职第一天讲长板）。绩效体系要简单：公平（是感觉不是客观存在：我所得/我付出 = 他所得/他付出；公布过程——周报、打卡、加班、拜访频率，高频+流程化；公平不是平均，宣贯一次后不再讨论，绩效必须有淘汰，管理者要人事权尤其出人权）+可信（兑现承诺，画过的饼拼命要来；反例：分校校长被迫压奖金导致队伍散）。绩效面谈五步（顺序固定）：目标回顾（有签字仪式感）→确认公平→复盘学习→下一轮目标→行动计划；频率月度或季度。金钱激励：最公平、要可见（奖金公开有仪式感、底薪密薪不动——保健因素 vs 激励因素：加薪加奖金不加底薪；与其降薪不如开人）、是社会标尺（勿逆人性）；金钱解决不了的两件事——超量疲惫（补意义）与角色不清任务冲突（补目标管理）；等效替换弹药库：晋升（平常储备、为下级谋发展）、信任/授权、同事关系（分工+绩效公平+淘汰）、工作本身（往"喜欢且擅长"迁移，用 S2 教练给反馈）。
- **管理三阶段（递进不可倒序）**：① 劳动效率=分工——新接团队先问领导"你要我来做什么"，调研三方（领导期待/客户需求/员工需求与不满）→科学划分工作元素→流程→岗位（岗位先于人，先写 JD）→配人（选择占 80%，换人如换刀）+按岗位需求培训（复盘=学习不是追责）→日常只沟通三件事：目标、授权、激励→平等对待（领导绩效=团队绩效之和，不下场替员工干活）。此阶段可拉动约 30%（【材料归纳】讲师经验数字，非实证承诺）。② 组织效率=专业水平+等级制度——权力与职位相关，职位与责任/目标相关、与薪酬待遇无关；让专业的人拿权做决策；管理本身也是专业，需持续进修；责权利分配形成上升通道，为下级谋发展。③ 个人效率=激励——为个人创造组织环境、满足需求、挖掘潜力，不设上限；先有劳动效率才有支付能力（先打胜仗再打大仗；忌新官上任先列招聘计划、先扩编）。传统管理者三问题：时间属于别人（做时间管理：目标、授权、激励三件重要的事）、不在其位不谋其政（练系统思考，盯全公司目标即 SMART 的 R）、只专注事忽视培养人。

冲突处理：与 goal-management 的分工——个人/单个目标口径拆解用 goal-management；带团队的目标工具选择、会议、绩效用本 Skill，重叠处以本课程表述为准并注明两来源。课程内部张力保留：不给答案 vs S1 命令型（按发展阶段匹配，不是一刀切）；绩效要淘汰 vs 承认个人需求（淘汰走绩效与法定程序，不是羞辱）。

# 3. 最小流程：带团队主循环

1. **定目标（占大头）**：判断业务类型选 KPI/OKR → 走"会前摸情况→会上摆事实列挑战→会后各自书写→分层汇总→下属说领导改大家认"→目标 SMART 化并白纸黑字确认。
2. **中段放手**：不问感受不问原因；领导看外部（对手/用户/资源），与员工保持"认苦劳"的软性沟通；新手一天一碰、好手一周一碰、顶尖一月一碰。
3. **节点收货**：问"事实是什么、问题是什么"；用六顶帽子或麦肯锡七步带团队复盘；绩效刚性兑现——达标激励、连续不达标培训/复盘/优化。
4. **按阶段升级行动**：识别员工/团队处于 D1—D4，换用 S1—S4；成熟一项授出一项（资源权+决策权），决策错了承担学费、复盘沉淀为 SOP。
5. **季度轮回**：绩效面谈五步 → 下一轮目标。

失败分支：员工不认目标 → 回查是否没让下属说、没有对标数据；会开成吵架 → 回查是否没统一帽子；授权后失控 → 回查是否没给 context、是否越过 SOP 频繁变动。

# 4. 第零步与后一步

第零步（向用户确认或按授权读取）：团队规模与业务阶段（新接/存量）；业务属熟悉还是探索；现有考核方式与人事权范围；本周期组织目标；用户在其中的角色（是否有下属、是否有管理者向其汇报）。

后一步：用户按方案执行后带回事实与结果（数字、会议记录、面谈反馈）；复盘差距归入目标问题、授权问题还是激励问题；有执行证据才可记录为应用，计划不算成果；新问题进入下一轮主循环。

# 反例

- 用户问"下属这事没干好，怎么追责"：不得顺着归因追责；转为"事实是什么、问题是什么、目标当时是否 SMART、谁来解决"。
- "新业务抖音账号帮我把 KPI 拆到每人每天"：应提示探索性业务宜用 OKR（定方向+个人响应），细拆 KPI 会扼杀探索。
- "帮我做一次绩效面谈，直接告诉员工被优化"：绩效面谈五步不承担解雇告知职能；解雇须按当地劳动法与公司流程，本 Skill 只提供分析。
- 课程中"抬现金发奖金""开人""底薪不动"等表述是讲师经验叙述【材料明确表达】，不构成劳动法或财务合规建议；落地前须按当地法规与公司制度核验【工程化护栏】。
