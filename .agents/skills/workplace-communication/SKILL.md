# 核心定义

职场沟通服务于工作结果的达成与高效达成。先问 what、why、原则，再进入 how；不要把技巧、讨好或猜测动机当成沟通本身。课程把有效沟通的三个目标概括为：减少误解、构建信任、产生结果；对应的基本原则是坦诚、利他、清晰。[XP-T-006#P003-P013]

# 使用流程

1. **先定义结果**：把“我想发展、希望支持、尽快做好”等抽象表达改写为可观察结果。必要时用 SMART 检查具体、可测量、可达到、相关和时间表。[XP-T-006#P016-P021]
2. **沟通前准备**：先回答“我需要什么、对方需要什么、双方能否形成共同目标”，再决定沟通渠道与表达方式。重要沟通优先准备，不把遭遇式沟通当默认模式。[XP-T-006#P014-P016]
3. **减少误解**：区分事实、推断和动机猜测；优先说清事实、影响、目标和边界，不靠“你应该懂我”推进。
4. **构建信任**：明确对方为什么值得参与、能获得什么、承担什么；“利他”不是讨好，也不是放弃自己的目标，而是让协作关系可持续。
5. **推动结果**：明确谁做、做什么、资源/授权、完成标准、时间节点和后续检查；没有责任人和时间表的讨论不能视为完成沟通。
6. **按关系调整**：向上沟通重在目标、判断依据与选项；向下沟通重在目标、资源、授权与验收；平级沟通重在共同目标与交换条件；客户沟通重在需求、边界和可交付结果。
7. **复盘**：检查三件事——误解是否减少、信任是否增强、结果是否推进；若没有，回到目标与准备环节，不只优化措辞。

# 护栏

- 不提供操纵、打小报告、羞辱、威胁或故意误导他人的话术。
- 不把“利他”解释为无条件让步，也不要求用户忽略职场边界、骚扰、歧视或安全问题。
- SMART、谈判、汇报等外部模型若超出课程材料，需按公共规则单独核验并标明工程化应用。
- 当前公司政策、劳动规则、薪酬市场和组织现实需要重新核验；课程案例不能直接当作当前事实。
- 对重要邮件、绩效、离职、薪酬或法律相关沟通，输出草案和风险点，不替用户批准重大动作。
