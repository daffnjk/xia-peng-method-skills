# 《学习之美》的按需应用

本参考属于 xia-peng-method-router。按 `03_agent/METHOD_POLICY.md` 区分刘澜原意、材料归纳与工程化应用。出处和详细页码查 `liulan-learning-book.md`，来源指纹查 `liulan-learning-source.json`。仅问书中内容时解释原意，不强制实践。

## 选择入口

- 学习没有进展：检查目标、挑战、方法、练习、反馈、动力，先处理最主要障碍。公式不是计分器，反馈可能延迟。
- 方法互相矛盾：区分事实、偏好与情境判断；检查假设、样本和适用条件，给可选择的条件分支。
- 知识很多但不成体系：围绕一个专题比较概念定义、关系及反例，形成暂定模式树；需要时再读全书提炼中六种模式学习方法。
- 读懂却不会用：使用四问检查吸收、联系、调整和应用。关系已清楚时可合并，不需要改造时保留原理。

## 四问应用卡（工程化模板）

复用用户已提供的材料和约束；必要输入是具体问题、相关经验和可用的应用机会。缺失时可以说明假设做示例，不假装完成实践。

1. 听：用自己的话概括要点及关系，给材料位置，区分原作者陈述与二手故事。
2. 想：联系相似、相反案例或自己的问题，说明共同关系和差异。只说一个人的名字不够，有明确关系的个人问题可以成立。
3. 变：说明保留项、调整项及失效条件。第三问“我变成什么”是改造知识，不是身份宣言。无需变化则解释为何适配。
4. 用：选择一个具体任务，写触发、动作、时间、结果证据和复盘时点。未执行标注待验证，模拟练习不算现实成效。

复盘时比较计划、实际动作、观察和推断。一次成功不是普遍规律，一次短期失败也不自动否定方法。讲解、教人和写卡片都不能代替实际应用。

## 选用技巧和边界

需要更多操作时再读全书提炼中的二十二技巧；不强制逐项使用。单次学习保留熟悉支点，长期累计扩展陌生范围，不能混用两种尺度。“近、远、创造性迁移”按刘澜教学分类解释，不冒称学界统一术语。作者案例和个人再阐释不充当已核验科学、历史或商业结论。

需要项目排期时调用 goal-management；需要封装方法时调用 scene-skill-builder；涉及已确定的职业能力试炼时由 career-planning 主导。本参考提供学习工具，不据故事执行职业或财务决定。
