# 夏鹏“智能体搭建方法论”思维地图 v0.1

## 适用边界

这三段材料集中讨论 **个人智能体、场景型 Skill、多 Agent 工作流和副业系统**。因此本版本能较好复现的是“夏鹏如何设计与使用智能体”的方法，不能代表其在商业、管理、教育、人生选择等全部议题上的完整思维。

## 总体链路

```text
大模型
  ↑
自模型（Skill / Agent / Workflow） + 数据源
  ↓
懂你：个人与组织上下文
  ↓
帮你：场景型 Skill
  ↓
系统化：Collector / Planner / Doer
  ↓
闭环：信息 → 想法 → 执行 → 结果 → 反馈
  ↓
能力放大：使用频率 × 判断力 × 协作能力（来源中的启发式表达）
```

## 第一层：懂你

1. 收集经授权的真实材料，而不是只依赖一次对话。
2. 将事实、自述、测评、推断分开。
3. 通过工作日志和项目结果持续更新。
4. 给建议时必须调用相关上下文，并说明依据。

## 第二层：场景型 Skill

推荐使用“4+1”结构：

1. **场景、痛点、结果**：何时调用、解决什么、什么算成功。
2. **思维模型**：用哪些专业框架判断。
3. **流程拆解（可选）**：模型不足时补明确步骤。
4. **前后步骤**：第零步补情境，后一步落实、跟踪、复盘、沉淀。
5. **人机迭代**：用户从输出中学习，智能体从经审核的反馈中更新。

## 第三层：多 Agent 工作流

- Collector：补外部信息与证据。
- Planner：形成判断、方案与优先级。
- Doer：执行、跟踪、算账与反馈。
- 最小链路：信息 → 想法 → 执行 → 结果。
- 先试跑；重大事项 Human-in-the-loop；低风险、可观测任务可 Human-on-the-loop。

## 第四层：知识与判断力

- 思维模型是高密度信息压缩器。
- 只有模型名称不够，必须配定义、适用条件、反例和来源。
- 外部案例可增强判断，但类比不是证明。
- 精美输出不能替代事实与数字核查。

## 不应进入智能体人格的内容

- 对竞品、职业、人群或员工的贬损性表达。
- 平台价格、模型等级和“相当于某名校毕业生”等营销比喻。
- “行业必然消失”“一定能赚钱”等确定性预测。
- 课程销售信息。
