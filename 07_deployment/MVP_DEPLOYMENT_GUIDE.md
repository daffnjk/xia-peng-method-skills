# MVP 部署指南

## 1. 当前正确产品名

首版建议命名为 **“夏鹏智能体方法论助手 v0.1”**，不要直接命名为“夏鹏思维分身”。原因是当前三段资料只覆盖智能体搭建方法。

## 2. 最小运行组件

1. 系统提示词：`03_agent/SYSTEM_PROMPT.md`
2. 资料库：三份 reviewed transcript + principle/case/model/claim 文件
3. 路由：`03_agent/ROUTER.md`
4. Skills：`04_skills/` 下六个 Skill
5. 评测：`06_evals/evals.jsonl`
6. 日志：保存问题、检索片段、答案、用户反馈和版本号

## 3. 知识库分层

- `source_transcripts`：保守校对稿，承担证据引用。
- `principles`：原则卡，承担方法检索。
- `cases`：案例卡，承担迁移与反例。
- `governance`：claim_audit、contradictions、model_registry，承担边界控制。

检索顺序：原则/案例 → 原始逐字稿回查 → 生成答案 → 来源与边界审查。

## 4. 在任意智能体平台落地

1. 新建主智能体，粘贴 SYSTEM_PROMPT。
2. 上传知识库四层文件。
3. 添加或复制 `04_skills` 中的 Skill。
4. 让路由器根据用户请求选择 Skill。
5. 将重要用户事实写入独立画像库，不与夏鹏知识库混存。
6. 对外发布、财务、法律、招聘和不可逆动作设置人工审批。
7. 运行至少 20 道黄金题后再开放给真实用户。

## 5. 首次验收

- 能回答三天课程主线并给来源。
- 被问完整职业教练十模型时明确资料不足。
- 被要求冒充夏鹏时拒绝。
- 能把新任务转成场景型 Skill。
- 能为复杂项目设计 Collector/Planner/Doer 与人工审批点。
- 不重复原文中的贬损和营销话术。

## 6. 下一批最值得补的资料

1. 职场教练完整 Word/PDF；
2. SMART、OKR、GRAI 等模型的夏鹏讲解原视频；
3. 夏鹏实际分析商业项目的完整案例；
4. 失败案例与改判案例；
5. 非 AI 主题的视频，用于扩展为真正的“夏鹏思维方式智能体”。
