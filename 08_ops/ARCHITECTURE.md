# 架构决策与迁移边界

日期：2026-09-05。目标：适用于个人和小团队的可验证方法论资产库；不是多用户在线 Agent 服务。

## 已落地的边界

`.agents/skills/` 是 Skill 唯一编辑源，YAML 是知识唯一编辑源，JSONL 是题库唯一编辑源，`METHOD_POLICY.md` 是公共运行规则唯一来源。`04_skills/` 保留迁移提示，不再容纳第二份 Skill。JSONL 导出、黄金题视图、审阅页面、完整运行包和发布清单由 `assets.py build` 生成在 `dist/`。

工程规则与方法论规则分开。宿主读取 AGENTS.md；方法任务读取公共规则；注册表声明主流程与可选辅助依赖，校验器拒绝不存在的依赖或循环。第三方 create-readme 是开发辅助资产，不进入运行白名单。

## 证据契约

原稿字节不变；`source_locks.json` 记录来源版本、路径与 SHA-256。XP-T-004 的实际段落可解析；前三个来源没有经核对的历史段落映射。迁移将旧编号放入 `legacy_source_refs`，有效 `source_refs` 降为来源 ID，回答必须同时给文件路径、回查原文并说明定位限制。

这不是把失效引用“修成准确引用”：保留历史但明确降低精度。`validate --strict-evidence` 会拒绝仍然只有文件级依据的资产。未来建立映射必须经原文核对，不能按旧编号或当前行数猜测。锚点解析只证明存在；是否支持结论仍需语义评测。

引用类型分成来源、原则、案例、模型、主张、冲突与 Skill。知识 statement 和案例 summary 的内容不因架构迁移而重写。evidence_type / confidence 描述来源支持，不表示现实效果验证。治理上下文以同来源保守关联，明确不是精准语义相关性。

## 构建与发布

构建使用固定文件白名单和固定 ZIP 顺序/时间，记录输入哈希、输出文件哈希与整体摘要；`validate --check-build` 验证目录和 ZIP 的成员与字节。运行包不含 inbox、私人资料、题库、标准答案、开发辅助 Skill 或测试文件。暂存 manifest 行也不会进入运行包。

内部构建保留必要证据，但不代表已经确认全部材料的使用授权。公共构建额外要求：精确证据、所有接入来源明确 authorized、绑定资产摘要和评分报告哈希的命名审批、同资产/题库的完整行为评分报告。公开可见不等于可再分发；public_source 状态不能通过授权门禁。

## 接入与故障模型

登记脚本在写入前校验输入、日期、manifest 结构、ID 和内容重复。写入使用独占锁、暂存目录和原子 manifest 替换；普通异常会清理尚未提交的接入目录。成功替换 manifest 是提交点。

它不是数据库级崩溃事务：强制终止、断电或不遵守锁的外部写入可能留下锁或孤立目录。看到遗留锁时，不自动删除、不覆盖重试；先确认无活动写入，核对 manifest 与 intake，再按提交点状态人工恢复。构建 `.dist-backup` 同理。

## 评测与宿主

Schema 校验、脚本单元测试、真实模型行为和实际工具安全分开。适配器协议只传题目，不传预期；评分器校验完整性和分数阈值，不自动断定语义正确。工作目录隔离不是权限沙箱，宿主应限制可读文件和可调用工具。

本项目不自建记忆数据库、模型服务、向量数据库、检索器或调度器。宿主按注册表和来源字段组织本地知识与引用定位。需要多用户服务时再引入身份隔离、任务状态、工具审批和运行日志，不能把这些能力归因于几个 Markdown 文件。

## 迁移与回退

一次性迁移脚本仅接受记录的旧知识与来源 blob SHA，防止覆盖并行编辑；完整迁移结果写入 `08_ops/migrations/2026-09-05-architecture.json`。旧文件仍可从原 Git commit 回查，不删除历史。

在独立分支完成迁移并审阅 diff。回退使用 Git revert 或切换到已确认的旧 commit，不从 dist 反向覆盖源目录。迁移脚本只处理固定基线，不是日常自动升级器。

## 仍需人工验收

前三份来源的精确映射、课程与第三方资产再分发授权、真实宿主/模型完整行为回归、适配器实际权限隔离仍需明确记录。CI 即使全部通过，也不能把这些事项改写为已完成。
