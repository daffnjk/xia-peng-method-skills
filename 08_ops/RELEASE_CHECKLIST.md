# 增量版本发布清单

本清单是验收门槛，不是已完成声明。没有执行的检查保持未勾选，并记录原因；纯文档或脚本维护也应说明未运行的模型行为测试。

## 来源层

- [ ] 新课程已分配唯一 `XP-T-xxx`，旧 ID 和旧锚点未改动。
- [ ] 原稿只读保存，校对稿与原稿分开。
- [ ] 人名、模型名、金额、比例、平台名已重点核验。
- [ ] 无法确认的词已进入 `uncertain_terms.md`。
- [ ] 授权状态和使用范围已登记；对外发布前已确认课程与第三方资产的使用条件。
- [ ] 来源引用能在实际文件中定位；历史锚点缺口没有被伪造编号掩盖。

## 知识层

- [ ] 每条新原则标注 `explicit / summarized / inferred` 与置信度。
- [ ] 重复内容已合并为来源补强，没有制造同义卡片。
- [ ] 新旧冲突没有被静默覆盖。
- [ ] 只有名称、没有定义的模型已进入 `model_registry.yaml`。
- [ ] 营销、预测、价格和收益类主张已进入 `claim_audit.yaml`。
- [ ] 案例卡区分事实、讲者判断、系统归纳和未知结果。
- [ ] 修改原则时已核对 YAML 与 JSONL 两种表示的一致性，没有重复索引。

## 智能体与 Skill

- [ ] `03_agent/SYSTEM_PROMPT.md`、`AGENTS.md` 的材料清单和适用边界在需要时同步更新。
- [ ] Router 只在任务域或路由行为需要变化时更新，使用真实存在的 router Skill 路径。
- [ ] Skill 版本号已按变更程度升级。
- [ ] 每个变更 Skill 都有触发条件、禁用条件、输入输出和验收标准。
- [ ] 没有把夏鹏未明确说过的工程实现写成其原话。
- [ ] `04_skills/` 与 `.agents/skills/` 的共享文件已审阅并同步；运行目录独有资源未误删。

## 工程与文档

- [ ] `python3 scripts/verify_codex_setup.py` 通过。
- [ ] `python3 scripts/sync_codex_skills.py --check` 通过，且已单独审阅需要删除或重命名的资源。
- [ ] `python3 -m unittest discover -s tests -v` 通过。
- [ ] `git diff --check` 通过；README、部署指南与实际文件、命令参数一致。
- [ ] 变更中没有私人资料、密钥、未经授权的原稿分发或敏感评测输出。

## 行为评测与发布

- [ ] 每条重要新原则至少有一条来源复现题。
- [ ] 每个新/变更 Skill 至少有迁移题和边界题。
- [ ] 按 [评测说明](../06_evals/README.md) 全量运行新旧题；记录 commit、宿主/模型、检索配置、逐题评分和失败原因。
- [ ] 每题总分至少 20/25，来源忠实度与边界意识均至少 4 分；未解决的关键失败阻止发布。
- [ ] 没有把文件检查或脚本单元测试冒充模型行为回归。
- [ ] 新版本已记录变更、兼容性、已知问题和可用的回滚 commit；没有提前宣称新版本已发布。
- [ ] 涉及外部知识库或生产索引时，先验收测试环境，再替换生产环境，并保留可回退配置。
