# 发布检查

- [ ] 来源原稿与锁一致，校对和锚点经过核对；没有把历史 legacy_source_refs 当有效引用。
- [ ] JSON Schema、ID、类型化引用、Skill 版本/依赖和循环检查通过。
- [ ] 来源授权与公开分发范围已明确；public_source 不等于再分发授权。
- [ ] 单元测试通过，失败恢复与重复输入已覆盖。
- [ ] 构建与 --check-build 通过；运行包没有私人资料、inbox、题目预期或开发辅助 Skill。
- [ ] 真实宿主行为评测逐题完成，资产/题库摘要吻合；模型、宿主、实际答案、检索证据和评分有记录。
- [ ] 宿主权限与高风险动作审批独立验收，没有将提示词当成技术隔离。
- [ ] 公共发布具备绑定当前资产摘要与报告哈希的命名审批，--public 门禁通过。
- [ ] 变更、人工未决项、兼容性和回退 commit 已记录。未创建未经批准的发布标签或生产部署。

审批格式见 `release_approval.example.json`。示例默认 public_distribution=false，不可直接用于发布。
