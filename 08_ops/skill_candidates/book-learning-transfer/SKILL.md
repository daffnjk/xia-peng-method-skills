# 1. 场景、痛点、结果

适用：读书或听课记了很多却难应用；只存碎片没有模式；想把案例迁移到自己的工作；需要检查学习方案的条件与证据。

痛点：把收藏当学习、把理解当应用、把他人答案当标准、跳过“想”就写行动、没有具体应用场景。

结果：一份能区分原意与个人调整的四问记录；一个有条件、反例和具体场景的行动模式；执行后才记录真实反馈。

不适用：只问原文含义时，不强制四问或画像；没有相关内容时，不假装读过；高风险专业决策不以本书替代专业核验。

# 2. 思维模型与来源

封装方法来自现有 `scene-skill-builder` 与 XP-T-002（`01_source/raw/XP-T-002_raw.txt`；仅文件级定位）。学习方法来自刘澜，不得署成夏鹏原话。

唯一知识编辑源：`02_knowledge/principle_cards.yaml`，本模块卡号 XP-P-049—072。
来源记录：`01_source/reviewed/XP-T-005_reviewed.txt`，P001—P024是24组视觉选段记录锚点，不是原书自然段。精确引用回查原PDF；记录包含短摘、标题和要点转述，不是全书逐字稿。

按需使用，不机械串联：
- 先检查旧习惯：反学习、ICAP（XP-P-051—052）。
- 判断是否可照用：参考答案、洞见分类（XP-P-053—055）。
- 收敛学习范围：聚焦八规则和四种读书法（XP-P-056—057）。
- 建立结构：模式功能与类型、SOLO、六种模式化方式（XP-P-058—062）。
- 转化应用：四种迁移、四问及22个技巧（XP-P-063—070）。
- 公式只作关系提示；填写笔记不算完成“用”（XP-P-071—072）。

冲突处理：聚焦不是禁止发散；放大长板不是忽视阻断性短板；个人诠释不改变作者原意；相似案例不证明迁移有效。保留两位作者的来源归属，关联不是合并署名。

# 3. 最小流程

## 听：我听到什么？
输入：用户授权材料及一个实际问题。
动作：复述材料原意，记录作者、来源ID、印刷页/PDF跨页；把无法确认的文字列为缺口。
输出：原意、关键术语、条件、证据定位。不得把“我觉得作者应该说什么”写成原意。

## 想：我想到什么？
动作：用归类、分类、类比建立知识联系；指出共性、差异和失效条件。
输出：一个关系清楚的模式，而非名词清单。对照原场景A、模式X、目标场景B；相关或类比不冒充因果。

## 变：我变成什么？
含义：第三问是按自己的理解和需要调整所学内容，使其便于应用；不是描述自己成为哪类人，也不是只写身份愿望。保留书中问法，不改写为另一套四问。
动作：按自身条件选择动词化、放大、缩小、移植、增加、减少、颠倒或杂交中的必要操作。
输出：原模式、修改理由、个人行动模式；明确标为【工程化外推】或【个人调整】，不倒写为作者原话。
信息不足时给条件分支或问一个关键问题，不造个人经历。

## 用：我用到哪里？
动作：限定一个具体情境，写“如果……就……”，约定执行后的反思；必要时用教导他人澄清理解。
输出：场景、触发条件、动作、可观察证据、失败/停止条件。
状态只能是“计划／已执行／已反馈”，没有实际执行证据不得跳到后两项。计划、讲解、笔记均不是应用本身。

失败分支：回查听错、联系不当、调整失真、情境不适用、道理本身有问题；不得一律归咎于不努力。

# 4. 第零步与后一步

第零步：确认材料范围、学习问题、相关已有知识、使用场景与现实限制。复用已有授权上下文；不强制读取私人画像。

后一步：由用户实际应用后提供反馈。只把经确认的事实写入获授权的位置；模板和例子不能写成用户成果。新问题进入下一轮四问；模型更新保留旧版本与适用条件变化。

# 5. 人机迭代与验收

人：能复述原意、解释联系、说明为何调整，区分计划与实际效果。
机：只提出知识卡/Skill候选变更，等待审阅；不静默更改作者归属或授权状态。

输出模板：
1. 问题与条件。
2. 我听到什么：原意和来源。
3. 我想到什么：关系、差异、反例。
4. 我变成什么：调整后的行动模式与外推声明。
5. 我用到哪里：具体情境、行动、证据、反思点和状态。
6. 缺口与边界。

人工验收：原意忠实、关系可解释、条件匹配、行动具体、状态真实。单纯复述题可只输出第2和第6项。

评测人员读取唯一题库源 `06_evals/learning_beauty_evals.jsonl`；本目录不维护第二份题库。被测模型不能读取预期答案。现有运行包可用于书籍知识与公共规则回归；候选工作流的行为验收须由评测宿主另行挂载本候选文件及必要来源，保持题库预期隔离，不因此将候选写入正式注册表。先做静态校验，再用真实宿主做行为评测，不能把自评、语法通过或题目数量当作通过率。

# 反例

用户说“学完了四问，准备下周用”，不得回答“已完成学习迁移”；只能记为计划。用户要求“按本书算我的学习力分数”，应解释公式是关系隐喻，不编造量表。
